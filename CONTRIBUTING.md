# Contributing to Elite Tech Shop

First off, thank you for considering contributing — this project thrives on community chaos and collaboration 🚀  

## How You Can Contribute
- **Report issues** → Use GitHub Issues for bugs, feature requests, or questions.  
- **Suggest ideas** → Drop them in Discussions or Issues.  
- **Improve docs** → Fix typos, clarify instructions, or add examples.  
- **Submit code** → Fork the repo, make changes, and open a Pull Request.  

## Pull Request Process
1. Fork the repository and create your branch from `main`.  
2. Make sure your code builds and runs locally.  
3. Add or update tests if relevant.  
4. Ensure your changes follow the project’s style and structure.  
5. Open a Pull Request with a clear description of what you changed and why.  

## Community Guidelines
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md).  
- Be respectful and constructive in Issues, PRs, and Discussions.  
- Early access contests (like the 5.0 hype) may be announced in Issues — engage there if you want insider perks.  

## Getting Help
- Check existing Issues and Discussions before opening new ones.  
- If you’re stuck, ask in Discussions — someone may have the answer.  
- For urgent matters, contact the maintainer at **arts009009009@outlook.com**.

# Elite Tech Shop — Source Code

This folder contains the full source code of Elite Tech Shop.  
Browse the code directly, explore backend and frontend, and contribute via pull requests.

## Structure
- **backend/** → Spring Boot, Rust, Go services
- **frontend/** → React + Next.js app
- **scripts/** → Dev utilities
- **tests/** → Playwright + unit tests
- **configs** → `.npmrc`, `docker-compose.yml`, `package.json`, etc.

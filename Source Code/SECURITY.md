# 🔒 Security Policy

## Supported Versions
We provide security updates for the following versions of Elite Tech Shop:

| Version | Supported |
|---------|-----------|
| 4.x     | ✅ |
| <4.x    | ❌ |

## Reporting a Vulnerability
If you discover a security issue, please **do not open a public GitHub issue**.  
Instead, report it responsibly:

- 📧 Email: arts009009009@outlook.com  
- 🛡️ Discord: DM **arts009009009** in the official server → [Join Here](https://discord.gg/H9E3u9pGDk)  
- 🔐 Provide details: affected version, reproduction steps, and potential impact  

### Response Timeline
We will:
- Acknowledge receipt within **7 days**  
- Investigate and confirm the issue  
- Provide a fix or mitigation plan  
- Credit responsible disclosure in release notes (if desired)  

## Security Best Practices
- Always run the latest supported build (currently **4.x**).  
- Keep dependencies updated (`pnpm install`, `pnpm update`).  
- Avoid exposing **pre‑release builds** to production environments.  
- Release builds are safe for production use, but pre‑releases may contain instability.  

## Disclaimer
Elite Tech Shop is in **active development**. Pre‑release builds may contain unstable or experimental features.  
Use at your own risk and report issues promptly.  
Release builds can be deployed to production environments with confidence.

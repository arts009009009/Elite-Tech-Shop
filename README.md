
# ⚡ Elite Tech Shop

A **React demo e‑commerce application** with a **neon‑dark Elite Tech vibe**.  
Built for chaos, speed, and full‑stack experimentation.

---

## ✨ Features
- **Product Catalog** → fetched from Local JSON  
- **Cart System** → add, remove, and persist items  
- **Watchlist** → save products for later using localStorage  
- **Responsive UI** → cyberpunk‑inspired CSS with neon styling

All versions follow **Major.Minor (Build X)** format:

**Current Version:** `4.4 (Build 328)`

## 🛠️ Install & Run Locally (Latest Version)

⚠️ **Note:** This guide only supports the absolute latest version  

- For version `4.4 (Build 328)` → replace step 5 with **Setup Rust backend**  
- For versions under `4.4 (Build 328)` → skip step 5 and Rust backend completely  
- For versions `4.5 (Build 330)` and up → follow steps 1–5 directly  

1. Download the repo as a ZIP from GitHub and extract it  
2. Navigate into the project folder:  
   ```bash
   cd elite-tech-shop
   ```
3. Install dependencies:  
   ```bash
   pnpm install
   ```
4. Start frontend:  
   ```bash
   pnpm run dev
   ```
5. Start backend:  
   ```bash
   pnpm run backend
   ```

### Setup Rust backend (required after 4.4 Build 328)
```bash
cd backend
cargo run
```

⚠️ **Note:** Project won’t work without Rust backend in versions after `4.4 (Build 328)`  
⚠️ **Note:** Project won’t work without Java backend in versions after `4.5 (Build 330)`

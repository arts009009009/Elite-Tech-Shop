# Elite Tech Shop

A React demo e-commerce application with a neon-dark Elite Tech vibe.

## Features
- Product Catalog — fetched from DummyJSON / Fake Store API
- Cart System — add, remove, and persist items
- Watchlist — save products for later using localStorage
- Responsive UI — styled with cyberpunk-inspired CSS

## Versioning

All versions follow Major.Minor (Build X) format.
- Patch field removed for clarity
- Build counter reflects raw tally of fixes and commits
- Minor increments mark new feature cycles
- No double digits in minor field — overflow rolls into next major

Example: 3.8 (Build 77)

Current Version: 4.0 (Build 77)

## Install & Run Locally

1. Download the repo as a ZIP from GitHub and extract it
2. Navigate into the project folder: cd elite-tech-shop
3. Install: npm install
4. Start: npm run dev or npm run preview
